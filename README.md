## How to Run Locally

1. Open Visual Studio Code
2. Click Clone Git Repository on the welcome page
3. Enter the url:
   https://github.com/tamandakamoto/Personal-Portfolio-Site.git
4. Click Clone from Github
5. Select a destination folder for the repository
6. Open the folder then open index.html then right-click it then open it with the default browser.
